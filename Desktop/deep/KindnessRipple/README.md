# Kindness Ripple - Swift Student Challenge

Interactive, context-aware kindness tracker. 100% offline, pure SwiftUI.

- On-device AI with NaturalLanguage (NLTagger.sentimentScore)
- Data viz with Swift Charts
- Observation framework, 3-minute judging arc

## Open
1. Clone this repo
2. Open KindnessRipple.swiftpm in Swift Playgrounds (iPad/Mac) or Xcode
3. Hit Run
4. Tap Simulate Judge Experience for instant demo

## Flow
- 00:00 Welcome
- 00:45 Context Challenge
- 01:30 Log reflection, gray to gold glow
- 02:30 Impact Dashboard

No network calls. All local.
